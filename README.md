
# 💹 Dashboard de Carteira de Investimentos | Power BI

Dashboard interativo para acompanhar uma carteira de investimentos em **ações** e **fundos imobiliários**, mostrando o total investido, o valor atual, a valorização e os proventos recebidos.

🔗 **[Alguns Dashboard no meu Portfólio ](https://sites.google.com/view/portifoliosamuelmarianomelo/in%C3%ADcio)**

## ✨ Recursos

- Indicadores de **Total Investido**, **Total Atual**, **% de Valorização** e **Total de Proventos**
- Tabela de **fundos imobiliários** com ticker, preço, preço médio e % de valorização
- Tabela da **carteira de ações** com ticker, preço, preço médio e % de valorização
- Proventos recebidos por descrição

## 🛠️ Tecnologias

Power BI Desktop · DAX · Power Query

## 🚀 Como abrir

Baixe o arquivo `.pbix` e abra no **Power BI Desktop**.

> ⚠️ Os dados deste dashboard são apenas para fins de demonstração e não representam recomendação de investimento.
